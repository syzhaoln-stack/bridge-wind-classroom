# 风特性 · 桥梁抗风交互课堂

面向初学者，支持电脑和手机。单文件 HTML，无外部运行依赖。

**在线学习：** https://syzhaoln-stack.github.io/bridge-wind-classroom/?v=4

## 七个实验

1. 平均风速与脉动风速。
2. 阵风与回看均线：3/5/10/60/600 秒窗口，同图动画与大号阵风系数。
3. 湍流度：标准差除以平均风速。
4. 风谱与时程：Kaimal、von Kármán、宽窄带教学谱；风速、湍流度、积分尺度直接联动到谱与完整 10 分钟时程，支持虚线对比和局部观察。
5. 逐段合成：12 个真实频带的离散积分，灰色已有波形 + 橙色本段波形 = 蓝色累计波形；可逐段加入或用 4 秒 / 12 秒动画演示。
6. 多点相关：区别沿风传播时延与横向波形差异，支持对齐到达时间与三行时程。
7. 风速沿高度分布：幂律与对数律。

调整参数时坐标固定，可手动查看大范围。平均风速 5–40 m/s，湍流度 0–50%；0% 时没有起伏。解释按需展开；支持当前模块 CSV 与 SVG 导出。

## 离线分发

下载 `index.html`，用浏览器打开即可。全部样式、交互代码及两份原 MATLAB 源码已经内嵌。分发只需这一个文件。

## 模型说明

单边谱积分为脉动方差。600 秒记录中有限频带一次校准到目标方差，再用 √(2SΔf) 和固定随机相位合成，逐段累计不再缩放。谱图采用固定对数轴，阴影只定位频带，数字显示实际积分。宽窄带为中心频率不同的教学分布；其中 L 是快慢控制尺度。沿风模型是理想冻结传播；横向模型描述空间相关性。公式、来源及边界在课件中说明。

本课采用合成样本帮助理解概念，不是实测风场或工程设计工具。
