# 第一课：风特性交互实验室

面向初学者的桥梁抗风课程交互课件，支持电脑和手机浏览。

**在线学习：** https://syzhaoln-stack.github.io/bridge-wind-classroom/

## 内容

- 平均风速与脉动风速
- 阵风风速与阵风系数：移动窗口取平均，逐步生成新曲线
- 湍流度：标准差与平均风速的比值
- 风谱：Kaimal 与 von Kármán 谱
- 多点风速相关性：三测点曲线、散点图和相关系数
- 风速沿高度分布：幂律与对数律

调整参数时保留图表预设坐标范围，便于比较变化。支持导出 CSV 数据和 SVG 图形。

## 离线分发

下载本仓库的 `index.html`，保存为 HTML 文件后用 Chrome、Edge 等浏览器打开即可。样式、交互代码及两份原 MATLAB 源码均已内嵌，不需要安装软件或联网加载资源。分发时只需发送这一个文件。

课件采用合成风速样本帮助理解概念。公式、模型适用条件和原代码来源可在页面中查看。

## 更新

修改 `index.html` 并推送到 `main` 分支后，GitHub Pages 会更新在线课件。
