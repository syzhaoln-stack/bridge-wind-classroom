建议课堂演示

坐标和合成样本

调整参数时坐标固定。超出范围时可手动选择“查看大范围”，图表不会自行缩放。平均风速范围 5–40 m/s，湍流度 0–50%；0% 时风速恒等于平均值。极端教学参数可能产生负的纵向速度分量，表示短时反向。只有“换一段风”才改变随机相位。

V(t) 是沿平均风方向的瞬时速度分量，u′(t) 是脉动。600 s 记录取 Δt = 0.25 s，单边 Kaimal 谱随机相位合成后，校准本段均值与标准差；它是有限带宽的教学模拟，非实测风。标准差使用分母 N。

风谱约定

单边谱，频率 f 以 Hz 计，∫₀∞ Sᵤ(f)df = σᵤ²。功率谱密度单位 (m/s)²/Hz。

Kaimal：Sᵤ(f) = 4σᵤ²(Lᵤ/Ū) / [1+6fLᵤ/Ū]⁵ᐟ³。

von Kármán：Sᵤ(f) = 4σᵤ²(Lᵤ/Ū) / [1+71(fLᵤ/Ū)²]⁵ᐟ⁶。常数采用 TurbSim 的圆整形式，积分有约 0.155% 的圆整误差。

风谱与时程、逐段合成分为两页，使用同一组 600 秒记录。可选择 Kaimal、von Kármán 或宽窄带教学谱，直接调节 Ū、I、L。有限频带内先一次性校准谱面积至 σ²，再使用 Aⱼ=√(2SⱼΔf) 与固定随机相位合成；图中显示实际使用的谱。1199 个频率小格分为 12 段，波组累计不再缩放。对数谱图的阴影只定位频带，数值积分才给出方差。宽带与窄带示例的中心频率不同，不视为纯带宽对照。

  • 白噪声示例改为具有时间相关性的谱合成风，以便解释积分尺度。
  • 原来标注为 Davenport 的公式校正为 Kaimal。统一风谱名称、频率和单位；本课保留核验后的 Kaimal 与 von Kármán。

本版区分理想沿风传播（B 晚到 d/Ū 秒，补偿时延可对齐）与横向相关性（形状会改变，不能只靠平移对齐）。三点时程显示完整 600 秒，可放大或分行比较。横向相关性：同一高度、沿桥轴横风方向的三个点，采用随频率与间距衰减的相关谱合成。原稿中的风力等级、规范地表类别与梯度高度部分随代码归档，宽窄带概念已加入交互实验。剖面是中性、匀质地表的概念比较，不套用规范地表类别；对数律设位移高度 d = 0，仅绘制 z ≥ 10 m。

%% 脉动风速的频率相关性示例
% 该示例展示了两组风速数据的生成，每组数据包含低频和高频成分。
% 低频成分（例如0.1Hz）在空间上具有高相关性，而高频成分（例如5Hz）在空间上相关性较弱（具有一定的相位差）。

% 清空环境
clear; clc; close all;

%% 参数设置
Fs = 100; % 采样频率 (Hz)
T = 60; % 总时间 (秒)
N = Fs * T; % 样本点数
U = 10; % 平均风速 (m/s)
sigma_low = 1; % 低频成分湍流强度 (标准差) (m/s)
sigma_high = 0.5; % 高频成分湍流强度 (标准差) (m/s)

% 设置频率
f_low = 0.1; % 低频成分 (Hz)
f_high = 5; % 高频成分 (Hz)

% 时间向量
t = (0:N-1) / Fs;

%% 生成两组具有高相关性的低频风速数据
% 低频风速在空间上具有较高的相关性
low_freq_component_1 = sigma_low * sin(2 * pi * f_low * t); % 位置1的低频成分
low_freq_component_2 = sigma_low * sin(2 * pi * f_low * t); % 位置2的低频成分 (完全相关)

%% 生成两组具有相位差的高频风速数据
% 高频风速在空间上具有较低的相关性，通过相位差体现
phase_difference = pi/2; % 相位差（45度）
high_freq_component_1 = sigma_high * sin(2 * pi * f_high * t); % 位置1的高频成分
high_freq_component_2 = sigma_high * sin(2 * pi * f_high * t + phase_difference); % 位置2的高频成分（有相位差）

%% 合成两组脉动风速数据
u_1 = U + low_freq_component_1 + high_freq_component_1; % 位置1的总风速
u_2 = U + low_freq_component_2 + high_freq_component_2; % 位置2的总风速

% MATLAB 脚本：风速剖面绘制

% 定义基本风速 (单位：m/s)
V_base = 38.4;  % 示例值，可以根据实际情况修改

% 地表类别定义及相关参数
surface_types = {'A', 'B', 'C', 'D'};  % 地表类别
conversion_factors = [1.174, 1.0, 0.785, 0.564];  % 转换系数
exponents = [0.12, 0.16, 0.22, 0.3];  % 指数率
gradient_heights = [300, 350, 400, 450];  % 梯度风高度

% 用户选择的地表类别和高度
selected_surface_type = 'D';  % 可以更改为 'A', 'B', 'C', 'D'
selected_height = 73;  % 可以更改为需要的高度

% 查找对应的转换系数、指数和梯度风高度
idx = find(strcmp(surface_types, selected_surface_type));
conversion_factor = conversion_factors(idx);
exponent = exponents(idx);
gradient_height = gradient_heights(idx);

% 计算10米高度处的风速
V_10m = V_base * conversion_factor;

% 定义高度范围
heights = linspace(1, 500, 1000);

% 预设风速剖面矩阵
V_profiles = zeros(length(heights), length(surface_types));

% 计算不同地表类别的风速剖面
for j = 1:length(surface_types)
    for i = 1:length(heights)
        if heights(i) <= gradient_heights(j)
            V_profiles(i, j) = V_base * conversion_factors(j) * (heights(i) / 10) ^ exponents(j);
        else
            V_profiles(i, j) = V_base * conversion_factors(j) * (gradient_heights(j) / 10) ^ exponents(j);  % 超过梯度风高度，保持不变
        end
    end
end

% 绘制风速剖面
figure;
hold on;
colors = {'r', 'g', 'b', 'k'};  % 为每种地表类别分配颜色
line_widths = [1, 1, 1, 1];  % 默认线宽

% 高亮用户选择的地表类别
line_widths(idx) = 3;  % 高亮选择的地表类别
for j = 1:length(surface_types)
    plot(V_profiles(:, j), heights, 'Color', colors{j}, 'LineWidth', line_widths(j));
end

% 绘制10米高度处的风速横线
plot([0, V_10m], [10, 10], 'k--', 'LineWidth', 1); 
text(V_10m, 10, sprintf('10m: %.2f m/s', V_10m), 'VerticalAlignment', 'bottom', 'HorizontalAlignment', 'left');

% 在选择的高度处绘制横线
V_selected_height = V_10m * (selected_height / 10) ^ exponent;
plot([0, V_selected_height], [selected_height, selected_height], 'k--', 'LineWidth', 1);
text(V_selected_height, selected_height, sprintf('%.1fm: %.2f m/s', selected_height, V_selected_height), 'VerticalAlignment', 'bottom', 'HorizontalAlignment', 'left');

% 图形设置
xlabel('风速 (m/s)');
ylabel('高度 (m)');
title('不同地表类别的风速剖面');
legend(surface_types, 'Location', 'northwest');
grid on;
hold off;

fprintf('基本风速，10米高度处风速为 %.2f m/s\n', V_base);
fprintf('地表类型 %s，桥梁设计基本风速 10米高度处风速为 %.2f m/s\n', selected_surface_type, V_10m);
fprintf('设计基准风速 高度 %.1f m: 风速 = %.2f m/s\n', selected_height, V_selected_height);
